# 🌍 Real-Time Location Tracker

A web application that tracks and displays the real-time geolocation of multiple users on a map using **Socket.io** and **Leaflet.js**.

## 🚀 Features

- 📍 Tracks user location in real time
- 👤 Each user can set a custom name
- 📡 Uses Geolocation API with high accuracy
- 🗺️ Interactive map with **Street View** and **Satellite View**
- 📊 Displays the total number of online users
- ✅ Removes user markers when they disconnect
- 🔀 Prevents marker overlap using slight random offset

## 🛠️ Technologies Used

- **Socket.io** – Real-time communication between client and server
- **Leaflet.js** – Map rendering and marker management
- **OpenStreetMap** – Default street map tiles
- **Esri Satellite Imagery** – Optional satellite map tiles
- **HTML, CSS, JavaScript** – Frontend structure and logic
- **Node.js + Express** – Server-side logic
